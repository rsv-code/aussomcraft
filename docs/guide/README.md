# AussomCraft Guide

Add your own features to a Minecraft server by writing short text files. No
mod to install, no compiling, and no restart when you change something.

Written for people who have not done this before. Read in order.

1. **[What AussomCraft is](01-overview.md)** - what you can make, how the
   safety levels work, and what you need.
2. **[Getting started](02-getting-started.md)** - install it, write your first
   script, and react to things happening in the game.
3. **[Intermediate](03-intermediate.md)** - your own commands, timers, saving
   data, and getting a script approved.
4. **[Advanced](04-advanced.md)** - the dangerous level, keeping scripts fast,
   and handling scripts other people wrote.

For a different audience:

- **[How AussomCraft works](05-java-developers.md)** - the Java side. What
  the classes are and how they fit together, for anyone reading or changing
  the plugin itself rather than writing scripts.
- **[Testing](aussomcraft-testing.md)** - how to run the plugin on a real
  Paper server and check it by hand, using the scripts in `examples/`. Also
  what the automated tests can and cannot tell you.

For the full list of everything you can call, see the generated
[API reference](..).
