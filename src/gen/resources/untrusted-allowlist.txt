# Methods untrusted scripts may call.
#
# This is an allowlist and it is the whole untrusted API. A method not named
# here is not generated at that tier, whatever the rules would otherwise say.
#
# Each line is a fully qualified class followed by one method name. That is
# the point of the format: a bare method name does not name a method. Five
# classes on this tier declare getName, and allowing the name allowed all
# five at once. Naming the class means every line is a decision somebody
# made about one method on one type.
#
# It also makes the file fail closed. Adding a class to UNTRUSTED_TYPES in
# Rules.java now grants nothing until its methods are written here, where
# before it silently admitted every listed name the class happened to have.
#
# It is short on purpose. The tier used to be every Bukkit event plus eleven
# types, 2,481 declarations, and produced one security finding after another:
# readable command text, the world seed, MiniMessage click events that run
# commands, permission attachments. Every one was rule-consistent, because
# rules match on name shape and what matters is capability. A surface small
# enough to read in one sitting is worth more than a large one that is merely
# gated.
#
# The contents come from design/untrusted-api-research.md: the ten things
# small scripts actually do, of which the eight that are observation and
# messaging belong here. The other two, changing the world and moving
# players, are trusted.
#
# Before adding a line, read what Paper's own documentation says the method
# does, not what it is called. See the "Judging What Paper API Does" section
# of CLAUDE.md.
#
# Names are Paper's own, not the generated extern names, so overload renaming
# does not matter here: sendMessage is written once even though the generator
# emits sendMessage and sendMessage_ComponentLike from it.
#
# A listed method is still dropped if it takes arguments, unless it is one of
# the messaging methods, or if it returns something this tier cannot express.
# So a line here is permission, not a promise.
#
# One per line, grouped by class. Blank lines and # ignored.
