# Types sharing a simple name

Generated by com.lehman.aussomcraft.gen.Generator. Do not edit.

Aussom has no packages, so a type's name on the script side is
its simple name. Paper reuses simple names across packages, so
these collide. Every type is still generated: one keeps the bare
name and the rest are prefixed with their own package's last
segment, taking more segments when one is not enough.

Which one keeps the bare name is decided by the priority order in
com.lehman.aussomcraft.gen.Names, so it is the type a script author
would mean rather than whichever sorted last.
